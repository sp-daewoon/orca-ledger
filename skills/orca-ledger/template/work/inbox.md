# Ideas and deferred work

This is a capture list, not permission to start work. Keep detailed progress in linked topic ledgers.

Statuses: `idea` (possible idea), `planned` (decided for later), `in_progress` (started), `on_hold` (deferred), `done` (completed). Closing a topic for deferral does not mean done. Use a stable ID; keep source and date. Do not add sample tasks as real work.
